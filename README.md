# Engenharia de Software (UniRV) — Base de Conhecimento

Este repositório documenta, organiza e consolida meus estudos ao longo do curso de **Engenharia de Software**.
O foco é transformar cada disciplina em conhecimento aplicável, com registro de teoria, exercícios, implementações, erros, correções e reflexões críticas — com ênfase em **IA, Ciência de Dados e Redes Neurais**.

## Objetivos

- Organizar o conhecimento por **períodos → disciplinas → tópicos**
- Construir base sólida em:
  - Fundamentos matemáticos e algorítmicos
  - Engenharia de software (processo, arquitetura, qualidade, testes, confiabilidade)
  - Dados, IA e redes neurais (teoria + prática)
- Produzir artefatos reutilizáveis:
  - Resumos técnicos
  - Implementações “from scratch”
  - Estudos de caso e experimentos
  - Projetos integradores
- Registrar evolução real:
  - Dificuldades, erros, correções e decisões técnicas

## Estrutura do repositório

- `periodos/`  
  Conteúdo principal do curso, separado por período e disciplina.

- `trilha-ia/`  
  Trilhas transversais que conectam disciplinas a IA, ML e Deep Learning.

- `projetos-integradores/`  
  Projetos que cruzam múltiplas disciplinas em aplicações práticas.

- `ferramentas/`  
  Templates, scripts e utilitários para manter padronização.

## Padrão de documentação por disciplina

Cada disciplina segue a mesma estrutura para consistência:

- `README.md` (visão geral da disciplina)
- `01-fundamentos-teoricos/`
- `02-conceitos-e-modelos/`
- `03-exercicios-e-listas/`
- `04-implementacoes-praticas/`
- `05-conexoes-com-ia.md`
- `06-reflexoes-criticas.md`
- `referencias.md`

## Como navegar

1. Comece por `periodos/` e selecione o período atual.
2. Dentro do período, abra a disciplina desejada.
3. Use `05-conexoes-com-ia.md` para ver como o conteúdo se conecta ao objetivo em IA.

## Convenções

- Linguagem principal para implementações: **Python**
- Documentos: **Markdown** (clareza, versionamento e legibilidade)
- Cada novo conteúdo deve ser:
  - datado quando relevante (ex.: aula, lista, experimento)
  - rastreável (origem: aula, livro, artigo, paper)
  - reprodutível (passos, parâmetros, versão de libs quando houver)
