# Referências Gerais

Este arquivo reúne referências úteis e recorrentes ao longo do curso.  
As referências específicas de cada disciplina ficam em `referencias.md` dentro da pasta da disciplina.

## 1) Matemática (base para IA e engenharia)

- Álgebra Linear
  - Vetores, matrizes, espaços vetoriais, autovalores/autovetores
- Cálculo / Otimização
  - Derivadas, gradiente, métodos iterativos
- Probabilidade e Estatística
  - Distribuições, inferência, estimativa, testes, regressão

## 2) Ciência da Computação e Engenharia de Software

- Algoritmos e Estruturas de Dados
  - Complexidade, recursão, grafos, árvores, ordenação
- Sistemas Operacionais e Concorrência
  - Processos/threads, sincronização, deadlocks, escalonamento
- Engenharia de Software
  - Requisitos, arquitetura, qualidade, testes, confiabilidade
- Banco de Dados
  - Modelo relacional, normalização, índices, transações

## 3) IA, ML e Redes Neurais (trilha principal)

- Fundamentos
  - aprendizado supervisionado e não supervisionado
  - validação, overfitting, regularização
- Redes Neurais
  - perceptron, MLP, backpropagation
  - funções de ativação, otimização
- Engenharia de ML
  - pipelines, dados, versionamento, avaliação, métricas
  - reprodutibilidade e monitoramento

## 4) Padrão de citação (recomendado)

Para livros e artigos, use um padrão consistente. Sugestão simples:

**Livro**
- SOBRENOME, Nome. *Título*. Edição. Cidade: Editora, Ano.

**Artigo**
- SOBRENOME, Nome. “Título”. *Periódico/Conferência*, Ano.

**Recurso online**
- Nome do autor/organização. “Título”. Ano. Acesso em: AAAA-MM-DD.
